プライバシーポリシー

最終更新日: 2026年5月10日

1. はじめに

本プライバシーポリシー(以下「本ポリシー」)は、mamonis.studio(以下「当方」)が提供するモバイルアプリケーション「petlo.」(以下「本アプリ」)および関連サービス(以下あわせて「本サービス」)における個人情報および利用者情報の取扱いについて定めるものです。

利用者が本サービスをダウンロード・起動・利用した時点で、本ポリシーに同意したものとみなします。本ポリシーは、利用者と当方との間で法的に拘束力を持つ取り決めです。

2. 取得する情報

2.1 自動的に取得する情報

  • 端末識別子(端末内で生成される UUID v4 形式の deviceId、特定個人を直接識別しません)
  • OS 種別・バージョン、アプリのバージョン番号
  • API 通信時の IP アドレス・通信ログ(セキュリティ・不正利用防止のため)
  • クラッシュ・エラー情報(発生時のスタックトレース、不具合解析のため)

2.2 利用者が入力・登録する情報

  • ペット情報:名前、種類(犬/猫)、品種、性別、誕生日、体重、写真など
  • 記録データ:食事、排泄、嘔吐、体温、通院、ワクチン、日記、写真
  • 家族共有時に入力される情報:招待コード、グループ名
  • AI 相談機能で送信されるテキスト、写真

2.3 課金情報

本アプリのサブスクリプション(petlo Pro)の購入は Apple App Store または Google Play を経由して行われます。当方はこれらストアから購読状況(有効/無効、プラン種別、開始・終了日時)を取得しますが、クレジットカード番号や決済の詳細情報を当方が直接取得することはありません。

3. 情報の利用目的

取得した情報は、以下の目的で利用します。

  • 本サービスの提供・維持・改善
  • AI 相談機能の応答生成のため、Anthropic Claude API への送信
  • 家族共有機能におけるグループ内のデータ同期・表示
  • サブスクリプションの管理・特典の提供
  • 利用者からのお問い合わせ対応
  • 不正利用・規約違反の検知および防止
  • サービスの分析および改善(個人を特定しない統計処理)
  • 法令、適用される規制および司法手続きへの対応

4. 第三者への提供

当方は、以下のいずれかに該当する場合を除き、利用者の情報を第三者に提供しません。

  • 利用者の同意がある場合
  • 本サービスの提供に必要な範囲で、以下の業務委託先に委託する場合

4.1 利用する第三者サービス

  • Anthropic, PBC — AI 相談機能において、利用者が入力したテキストおよび画像を送信し応答を生成。Anthropic は API 経由で受領したデータを学習目的で使用しないと公表していますが、応答生成のために一時的に処理されます。
  • Cloudflare, Inc. — Pro 機能利用時のデータ保存・配信(Workers / D1 / R2 / KV)。データは Cloudflare のデータセンターに保管されます。
  • Apple Inc.、Google LLC — App Store / Google Play を介したサブスクリプションの管理および決済処理。

4.2 法令に基づく開示

法令に基づく開示請求(裁判所、捜査機関、税務当局等)があった場合、必要な範囲で情報を開示することがあります。

上記以外の目的で、利用者の情報を第三者に販売・貸与・提供することはありません。

5. データの保管場所と保管期間

  • 端末ローカル:利用者が本アプリを削除するまで端末内に保存されます。
  • Cloudflare(Pro 機能):全世界のエッジネットワークに分散配置されます。利用者がアカウントを削除するまで保管します。
  • AI 相談ログ:Anthropic 社のサーバーに一時的に保管され、Anthropic のポリシーに従って取り扱われます。
  • 削除リクエスト後:本アプリの「設定 > アカウント削除」から削除を実行した場合、当方は 30 日以内にクラウド側のデータを完全に削除します。

6. 利用者の権利

利用者は、当方が保有する自己に関する情報について、以下の権利を有します。

  • 情報へのアクセスおよびコピーの取得
  • 情報の訂正および削除
  • 情報の利用停止
  • データポータビリティ(機械可読形式での提供)
  • 同意の撤回
  • 監督機関への苦情申し立て

EU 一般データ保護規則(GDPR)、日本の個人情報保護法(APPI)、カリフォルニア州消費者プライバシー法(CCPA)等、適用される法令に基づく権利を尊重します。権利行使を希望される場合は、後述の連絡先までご連絡ください。

7. 子供のプライバシー

本サービスは 18 歳以上 の方を対象としています。13 歳未満の児童(米国 COPPA 準拠)からの個人情報を意図的に収集することはありません。13 歳未満の利用が判明した場合、保護者または本人からの申し出により、当該情報を速やかに削除します。

18 歳未満の方が本サービスを利用する場合は、親権者の同意のもとで利用してください。

8. データセキュリティ

  • 本アプリと当方サーバー間の通信は HTTPS で暗号化されます。
  • クラウド保管時は Cloudflare の標準的な保管時暗号化が適用されます。
  • 認証トークン(JWT および refresh token)は iOS では Keychain、Android では EncryptedSharedPreferences に保管されます。
  • エンドツーエンド(E2E)暗号化は実装していません。

上記の措置を講じていますが、インターネット上の通信およびクラウドサービスにおいて完全な安全性を保証することはできません。

9. クッキー・トラッキング

本アプリでは Cookie を使用しません。広告 SDK、第三者の分析 SDK、トラッキング SDK は導入していません。

10. 本ポリシーの変更

当方は、法令の変更や本サービスの内容変更に応じて、本ポリシーを変更することがあります。重要な変更を行う場合は、本アプリ内の通知または本ウェブサイトへの掲載により、利用者に通知します。
